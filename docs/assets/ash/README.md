# Bullet Age — Ash

These are the original Ash character assets copied from the user's local
`BulletAge-WorkingCopy` Unity project for use by this browser adaptation.

- `Ash.json`: Spine 3.7.87 skeleton and animation data.
- `Ash.atlas`: texture atlas metadata.
- `Ash.png`: packed character artwork.

Ash and the Bullet Age artwork are not covered by Celestefall's MIT license.
All rights to these character assets remain with their original owner.
